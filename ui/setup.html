The prompts, parsers and Live2D banks use the 69-key register_emotion vocabulary. The shipped MekaHime_Amika voice uses the old V1 tags (happy2, tsun3…). The adapter is ON by default: it maps the leading emotion tag to a V1 ID and changes the speaker while the face retains the original tag. Disable only for your own V2-native voice. Vision · she can see
Checking…

On the Use page, choose the camera button and grant permission to share camera frames with the configured vision service. Its descriptions become context for her replies.

Use page →

The local VLM (vision/vlm_service.py) subscribes to /ws/vlm_feed and describes changed scenes. Fresh descriptions (≤3 s) are appended to your turns with the literal protocol marker （你在视频中看到：…）. Her latest line is fed back as language-matched context. Configure settings.json → vision: qwen3-vl-2b (~4.3 GB VRAM, zh/en/ja default), qwen3-vl-4b (~9 GB), qwen2.5-vl-3b or smolvlm2-2.2b / -500m (English). Model changes require relaunch. The marker is not editable UI text.

You & Amika

{user_name} and {city} in prompts use your name and city. The time zone sets her clock, daily scenes, weekdays and memory dates. The first-run wizard also fills these in. UI language does not change the reply language, time zone or persona.

Personality

Edit her story, daily life and relationship. Use {user_name}, {city} and {weekday} as placeholders. Each daily slot has five possibilities [1]–[5], each with 20% probability. Changes save into her prompts with format checks. Editable source may be Chinese or English and is preserved as written, not translated when the UI language changes.

Text her · Discord & Telegram

Text only, no voice. Create a bot, paste its token and add your own user ID to the allow list. She replies to DMs (or @mentions in Discord servers). People outside the list receive their ID so you can add them. Tokens stay in config/messengers.json on this computer. Instant and full replies arrive separately. When she speaks first, she uses the last chat.

Danger zone

Wipe her memory

Deletes remembered conversations, facts and the transcript. Personality, names and settings stay. A local backup is kept in memory_f/backups/. Power off the stage first so she is idle. Type WIPE to confirm.

Reset everything

Restores shipped defaults: deletes memory (keeps a backup), restores personality files, and clears your name, city and clock. The first-run wizard returns on the Use page. API keys, bot tokens, voice and avatar settings stay. Type RESET to confirm.
