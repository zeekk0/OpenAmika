# OpenAmika 한국어 빠른 시작

[简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [English](README.md) | **한국어**

Amika는 내 PC에서 음성과 텍스트로 대화하는 AI 동반자입니다. 전체 설치 요구 사항과 자산 라이선스는 [영문 README](README.md)를 참고하세요.

## 한국어 사용하기

- 화면의 언어 선택에서 **한국어**를 선택하면 사용·설정·도구·소개·흐름 화면과 첫 설정을 한국어로 볼 수 있습니다. 화면 언어는 답변 언어·시간대와 독립적이며 이름·페르소나·기억을 바꾸지 않습니다.
- 한국어 입력 감지, 답변 언어 지정, 기억 조회와 도우미 결과의 한국어 유지가 지원됩니다. 답변 품질은 선택한 모델에 따라 달라집니다.
- `한국어로 말해 줘` 또는 `Please reply in Korean`이라고 요청하면 해당 차례에 한국어로 답하도록 지시합니다. 다음 차례는 다시 입력 언어를 따릅니다. 로마자로만 적은 한국어는 자동 판별하지 않습니다.
- 채팅과 첫 설정의 이름·도시 입력은 한글 조합 확정 Enter와 전송 Enter를 구분합니다. 조합을 확정한 뒤 다시 Enter를 누르거나 전송 버튼을 사용하세요.
- **한국어 음성은 실험적입니다.** TTS의 한국어 전처리 점검은 실제 발음·음질·마이크 인식 품질을 보증하지 않습니다. 자세한 내용은 [음성 문서](docs/TTS.md#korean-voice-status)를 참고하세요.

언어 모델은 **한국어 답변과 중국어 지시를 모두 이해할 수 있어야 합니다.** 내부 프롬프트와 생각 표현은 의도적으로 중국어입니다. `我说：`, `我心想：` 같은 프로토콜 토큰과 감정 태그를 번역하지 마세요. 기존에 직접 수정한 페르소나는 기본 템플릿의 한국어 언어 규칙을 수동으로 병합할 수 있습니다. 이를 위해 사용자 설정이나 기억을 초기화할 필요는 없습니다.

## 설치와 실행

기본 설치 경로는 Windows 10/11, Python 3.11과 NVIDIA GPU를 사용합니다. GPU·디스크 요구 사항과 CPU 옵션은 [설치 요구 사항](README.md#what-you-need)을 확인하세요. 한국어 지원이 운영체제 지원 범위를 바꾸지는 않습니다.

일반 PowerShell 창에서 [설치 안내](README.md#set-her-up)에 따라 저장소를 준비한 뒤 프로젝트 폴더에서 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup_windows.ps1
envs\brain\Scripts\python.exe scripts\setup_tts.py
.\Start_OpenAmika.bat
```

Python 3.11이 이미 준비되어 있다면 한국어 안내로 코어 설치를 실행할 수 있습니다. 이 명령은 환경과 모델을 다운로드·설치합니다.

```powershell
py -3.11 scripts\setup_core.py --lang ko
```

음성·Live2D·도우미 아바타에는 별도 이용 조건이 있습니다. 설치 프로그램이 표시하는 조건을 읽고 동의할 경우에만 직접 수락하세요. 화면 언어를 바꿔도 라이선스나 IoT 안전 동의가 자동으로 생성되지 않습니다.

실행 후 `http://localhost:53000`으로 접속하여 이름·도시·모델 설정을 마치고 대화해 보세요.

```text
안녕하세요. 오늘 어땠어?
내 이름은 민수야.
한국어로 말해 줘.
영어로 답해 줘.
```

## 점검과 문제 해결

```powershell
envs\brain\Scripts\python.exe launch.py --check --lang ko
py -3.11 scripts\setup_core.py --check --lang ko
envs\brain\Scripts\python.exe scripts\setup_tts.py --verify
```

`--lang en`으로 영문 안내를 볼 수 있습니다. `--help --lang ko`는 설치 없이 사용법을 보여 줍니다. 설정 키·점검 식별자·종료 코드는 번역하지 않으며 외부 프로그램의 오류 세부 내용은 원문으로 표시합니다. 실행 중 런처 대시보드는 영어입니다.

`setup_core.py --check`는 설치하거나 설정을 고치지 않습니다. `launch.py --check`는 서비스를 시작·중지하지 않지만 `logs/preflight.json`을 기록하고 설정된 상태 확인 주소를 조회할 수 있습니다.

| 증상 | 확인할 내용 |
| --- | --- |
| 한국어 대신 다른 언어로 답함 | `한국어로 말해 줘`로 확인하고 모델의 한국어·중국어 지원과 페르소나 언어 규칙을 확인하세요. |
| `Korean voice`가 `unavailable` | 표시된 패키지·사전을 음성용 Python 환경에 명시적으로 준비한 뒤 `--verify`를 다시 실행하세요. 점검은 자동 설치하지 않습니다. |
| 자막은 보이는데 한국어 음성이 없음 | 페이지를 한 번 클릭하고 음성 서버 오류를 확인하세요. 한국어 의존성이 없으면 중국어 발음기로 자동 대체하지 않습니다. |
| 한글 확정 Enter로 바로 전송됨 | OS·브라우저·입력기와 재현 순서를 기록하세요. 조합 확정 후 별도의 Enter나 버튼 클릭은 한 번만 제출되어야 합니다. |
| 설정이나 모델이 없다고 나옴 | `--check`는 설치하지 않습니다. 설치 상태를 확인하고 `scripts/setup_core.py --lang ko`의 안내를 따르세요. |

한국어 음성 서버는 한국어 전처리의 성공 결과를 프로세스 안에 보관합니다. 발음 패키지나 사전을 변경했다면 음성 서버를 다시 시작하세요. 일반 `/ping` 성공이나 한국어 전처리 성공만으로 실제 합성 품질을 판단하지 마세요.
